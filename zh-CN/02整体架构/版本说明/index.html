        版本说明

        本文档记录 Hi3516CV610 系列芯片 SDK 的版本更新历史。

        v1.0.0 (2026-06)

        新增

        • 视频输入（VI）

        • 新增VI和VPSS在线/离线通路支持

        • 新增线性和WDR数据通路支持
        • 新增3DNR支持
        • 新增VICAP-VIPROC离线卷绕支持
        • 新增用户送帧功能支持
        • 新增pipe/chn低延时支持
        • 新增通道后处理（包含COVEREX、LDC、旋转、CROP）支持

        • 新增支持虚拟pipe送raw支持，raw格式为：raw8/10/14/16

        • ISP

        • 新增黑电平校正BLC(Black Level Correction)支持

        • 新增动态坏点校正，坏点簇矫正支持
        • 新增Bayer降噪、固定噪声消除、Demosaic处理支持
        • 新增Gamma校正支持
        • 新增自动白平衡AWB(Automatic White Balance) 、自动曝光AE(Automatic Exposure) 支持
        • 新增3D降噪支持
        • 新增色彩校正矩阵(Color Correction Matrix)支持

        • 新增AIBNR 线性支持

        • 视频处理子系统（VPSS）

        • 新增离线、在线、离线从（VI离线VPSS在线）支持

        • 新增输入图像Crop、Cover支持
        • 新增通道输出图像Cover、Corner_Rect、Crop、Scale支持
        • 新增通道后处理（Rotation_Fixed/CoverEX/LineEx/Corner_Rect/LDC）支持
        • 新增扩展通道支持

        • 新增图像Mirror/Flip支持

        • 视频图形子系统（VGS）

        • 新增缩放、Cover、画线、旋转、Corner_rect、CROP支持

        • 视频编码

        • 新增H.264编码支持

        • 新增JPEG编码支持
        • 新增MJPEG编码支持
        • 新增码率控制（CBR/VBR/CVBR/FIXQP/QPMAP/AVBR/QVBR/ABR）支持
        • 新增Mosaic(H264/H26）支持
        • 新增隐私保护编码(H265)支持
        • 新增智能编码(SVC)2.0基本通路支持

        • 新增输入图像旋转、CROP支持

        • 区域管理（REGION）

        • 新增VI CoverEx叠加支持

        • 新增VPSS 输入Cover叠加支持
        • 新增VPSS 输出Cover/Corner_Rect/CoverEx/LineEx/Corner_RectEx叠加支持

        • 新增VENC 输入Overlay叠加支持

        • 智能子系统

        • 新增IVE智能多种算子支持

        • 新增图像分析引擎（NPU）支持

        • 新增智能算法（自研），如人脸人形车、包裹、宠物等检测支持

        • 音频（Audio）

        • 新增1*I2S接2-4路8K~48K 16Bit音频输入支持

        • 新增1*I2S接2路8K~48K 16Bit音频输出支持
        • 新增音频输入/输出重采样支持
        • 新增内置CODEC支持
        • 新增语音增强（Talk VQE）支持
        • 新增录音增强（Record VQE）支持
        • 新增双MIC拾音（TalkV2 VQE）
        • 新增内置G.711/G.726/ADPCM编码器支持
        • 新增内置G.711/G.726/ADPCM解码器支持

        • 新增外挂AAC/MP3/OPUS编解码器支持

        • 安全子系统

        • 新增AES加解密支持

        • 新增HASH 256/512支持
        • 新增HMAC 256/512
        • 新增ECC签名验签支持
        • 新增RSA加解密、签名验签支持
        • 新增国密 SM2/SM3/SM4算法支持
        • 新增PBKDF2 算法支持

        • 新增OTP读写支持

        • 工具

        • 新增PQTools工具支持

        • 新增AQTools工具支持

        • 新增SVP_NNN PC工具支持

        • 其他

        • UVC为内核原生V4L2，支持Device UVC 1.1 / UAC 1.0，，支持YUYV/NV12/NV21/MJPEG/H264/H265

        • 新增多个sample示例支持：aiisp、audio、region、svp、venc、vgs等

        不支持规格说明

        如下规格当前版本不支持，将在后续版本持续规划。

        • VI虚拟pipe送raw不支持raw12格式
        • ISP不支持smart ae
        • VGS不支持亮度和统计接口调用
        • VI-VPSS离在线不支持4组卷绕
        • JPEG编码不支持前级（VPSS）多源输入
        • 编码不支持mini buffer功能
        • 不支持tinyml库
        • 智能不支持2路及以上的aicpu模型在多个线程中同时运行
        • SVP_NNN_PC工具不支持IR构图功能，AIPP只支持均值方差，不支持FM/CROP/RESIZE/PAD功能
        • 不支持os和mmz内存调换，当前支持os在前、mmz在后的布局方式
        • 不支持mmz进程隔离
        • 不支持KOL

        v0.0.1 Beta (2026-03)

        新增

        • 初始版本发布
        • 支持 Linux 5.10 内核基础功能
        • 支持 I2C Sensor 接入，支持 Sensor 型号为 HY006-3814-0011
        • 支持视频输入（VI）：通过 MIPI_RX 接收视频数据
        • 支持视频处理子系统（VPSS）
        • 支持 H.265 编码
        • 支持 sample vie 示例：采集图像存储为 H.265 码流
        • 支持 ARM GCC 10.3.0 工具链
        • 支持 MUSL 1.2.4 C库
