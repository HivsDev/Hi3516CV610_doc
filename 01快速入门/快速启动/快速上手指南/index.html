    快速上手指南

    本文旨在指导开发者快速运行第一个Hi3516CV610的第一个样例（sample），本文的开发板为HiPi CV610 生态开发板，下文所指代的开发版即指代该单板。

    快速开始

    1. 下载镜像

    从此处可以下载到已经预制的镜像包，本文以预制镜像Hi3516CV610_V1.0.1.tar.gz为例进行说明。

    • 进入页面下载镜像包Hi3516CV610_V1.0.1.tar.gz。

    • 解压Hi3516CV610_V1.0.1.tar.gz，解压后的目录如下，更详细的说明可以参考发布页面的README.md。
    ├── image/     # 系统镜像文件
├── sample/    # MPP 示例程序
└── ko/        # MPP 内核驱动模块

    2. 烧录镜像

    烧录工具为ToolPlatform工具，下载地址，ToolPlatform工具的指导可以参考这里。

    按照如下顺序完成烧写工作：

    • 参考开发板的硬件指南完成开发板和PC的连线,，包括电源线、调试串口线、网线的接入。

    • 在PC上的"设备管理器"-"端口（COM和LPT）"中确认开发板调试串口的COM序号，下文假设是COM1。

    • 解压下载的ToolPlatform工具，解压后在目录下存在ToolPlatform.exe文件，双击打开。

    打开后首次需要选择芯片Hi3516CV610

    点击BurnTool进入主页面，根据BurnTool工具使用指南完成界面相关参数的配置，串口即第二步获取的串口号，传输方式选择网口，板端IP和PC端（服务器）IP需要在同一网段。

    • 当前开发板是nand flash类型，因此选择镜像包中的nand_burn_table.xml（位于镜像包解压后的image目录下）。

    • 点击"烧写"按钮，重新上下电开发板后会启动烧录，烧录完成会弹出完成按钮，预计耗时10分钟左右。

    3. 启动单板

    烧录完成后，使用串口工具/网络工具连接并登录单板，默认用户名是root，默认密码是空。

    登录成功后，可以通过如下方式确认是否正常。

    1. 确认ko是否已经加载。

    执行lsmod命令，结果如下：

    1. 确认媒体服务进程sdk_server是否已经启动。

    执行ps命令查看，结果如下

    4. 运行样例

    发布镜像已经将sample_vie样例放到镜像的/user/bin目录下，直接执行sample_vie命令即可运行视频数据采集到存储2路H.265码流的完整通路。

    ~ # sample_vie 0
vi vpss mode list:
    (0) VI_ONLINE_VPSS_ONLINE
    (1) VI_ONLINE_VPSS_OFFLINE
    (2) VI_OFFLINE_VPSS_ONLINE
    (3) VI_OFFLINE_VPSS_OFFLINE
please select mode:
0
……
---------------press enter key to exit!---------------

    会在运行sample_vie的目录下生成码流文件。

    可以将stream_chn0.h265或stream_chn1.h265导出，使用VLC播放器播放。
