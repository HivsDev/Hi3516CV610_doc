        ot_nr_v2

        【说明】

        定义3DNR X接口版本V2的参数。

        【定义】

        typedef struct {
    ot_nr_v2_pshrp  iey;
    ot_nr_v2_sfy  sfy[3];
    ot_nr_v2_mdy  mdy[2];
    ot_nr_v2_tfy  tfy[2];
    ot_nr_v2_nrc0  nrc0;
    ot_nr_v2_nrc1  nrc1;
    ot_nr_v2_sfy_lut luty[2];
    ot_nr_v2_pp  pp;
    ot_nr_v2_mdy0  mdy0;
    struct {
    td_u8 nry1_en         : 1;
    td_u8 nry2_en         : 1;
    td_u8 nry3_en         : 1;
    td_u8 nry4_en         : 1;
    td_u8 nrc0_mode       : 1;
    td_u8 nrc_en          : 1;
    };
} ot_nr_v2;

        【成员】

        成员名称

        描述

        iey

        亮度滤波增强模块参数。

        sfy

        亮度滤波空域滤波参数。

        mdy

        亮度滤波运动检测参数。

        tfy

        亮度滤波时域滤波参数。

        nrc0

        色度滤波C0级参数。

        nrc1

        色度滤波C1级参数。

        luty

        亮度滤波空域滤波曲线参数。

        pp

        3dnr后处理参数。

        mdy0

        亮度滤波预处理时域滤波参数。

        nry1_en

        亮度滤波N1级使能开关。取值范围：[0, 1]

        nry2_en

        亮度滤波N2级使能开关。取值范围：[0, 1]

        nry3_en

        亮度滤波N3级使能开关。取值范围：[0, 1]

        nry4_en

        亮度滤波N4级使能开关。取值范围：[0, 1]

        nrc0_mode

        色度滤波C0级模式选择。取值范围：[0, 1]

        nrc_en

        色度滤波使能开关。取值范围：[0, 1]

        【3DNR X接口与MPI接口的对应关系】

        • en 对应于nry1_en、nry2_en、nry3_en、nry4_en，默认参数分别为1、1、1、1；
        • nCmode对应于nrc0_mode，默认参数为0；
        • nCen对应于nrc_en，默认参数为1。

        ot_nr_v2_pshrp

        【说明】

        3DNR后增强模块参数。

        【定义】

        typedef struct { 
    td_u16 coarse_g1, coarse_g2, coarse_g3, coarse_g4; 
    td_u16 fine_g1, fine_g2, fine_g3, fine_g4;
    td_u16 o_sht_b, u_sht_b;
    td_u16 o_sht_f, u_sht_f;
    td_u16 sfn7_0, sfn7_1, sfn8_0, sfn8_1;
    td_u16 sf_bld[17];
    td_u16 shp_ctl_mean[17], shp_ctl_dir[17];
    td_u16 sth1_0, sth2_0, sth3_0, sth1_1, sth2_1, sth3_1;
    td_u16 sfn0_0, sfn1_0, sfn2_0, sfn3_0, sfn0_1, sfn1_1, sfn2_1, sfn3_1; 
} ot_nr_v2_pshrp;

        【成员】

        成员名称

        描述

        coarse_g1, coarse_g2, coarse_g3, coarse_g4

        中频信息增强的强度，1~4对应不同增强滤波器。

        取值范围：[0, 1023]

        fine_g1, fine_g2, fine_g3, fine_g4

        高频信息增强的强度，1~4对应不同增强滤波器。

        取值范围：[0, 1023]

        o_sht_b, u_sht_b, o_sht_f, u_sht_f

        o_sht(over shoot control), u_sht(under shoot control)分别表示抑制增强导致的白边和黑边。f和b分别表示前景和背景。数值越小，表示抑制能力越强，即增强越弱。

        取值范围：[0, 255]

        sfn7_0, sfn7_1, sfn8_0, sfn8_1

        用于混合的滤波器号（7号、8号混合滤波器）。

        取值范围：[0, 4]

        sf_bld[17]

        7号、8号混合滤波器的混合曲线（共用一条曲线）。混合指标分别为边缘方向性、亮度。

        取值范围：[0, 63]

        shp_ctl_mean[17], shp_ctl_dir[17]

        用于抑制噪声不被增强的曲线（仅作用于1号和2号滤波器的中频信息增强（coarse_g））。纵坐标数值越小，表示增强越弱。

        取值范围：[0, 63]

        sth1_0, sth2_0, sth3_0, sth1_1, sth2_1, sth3_1

        运动前景和背景区域的保边阈值。根据阈值选择使用不同的滤波器，需要配合sfn使用。

        取值范围：[0, 511]

        sfn0_0, sfn1_0, sfn2_0, sfn3_0, sfn0_1, sfn1_1, sfn2_1, sfn3_1

        根据sth保边阈值，不同图像特性选择不同滤波器的类型（滤波器号），其中0、5、6号滤波器为输入。

        取值范围：[0, 8]

        【3DNR X接口与MPI接口的对应关系】

        • N4级的nXsf1 对应于iey.coarse_g1、iey.fine_g1，默认参数分别为128、128；
        • N4级的nXsf2 对应于iey.coarse_g2、iey.fine_g2，默认参数分别为128、128；
        • N4级的nXsf3 对应于iey.coarse_g3、iey.fine_g3，默认参数分别为128、128；
        • N4级的nXsf4 对应于iey.coarse_g4、iey.fine_g4，默认参数分别为128、128；
        • N4级的nXsf7 对应于iey.sfn7_0、iey.sfn7_1，默认参数分别为0、0；
        • N4级的nXsf8对应于 iey.sfn8_0、iey.sfn8_1，默认参数分别为0、0；
        • N4级的nXsht 对应于iey.o_sht_f、iey.u_sht_f、iey.o_sht_b、iey.u_sht_b，默认参数分别为80、80、80、80;
        • N4级的nXsfn对应于 iey.sfn0_0、iey.sfn1_0、iey.sfn2_0、iey.sfn3_0，默认参数分别为4、4、4、0;
        • N4级的nX2sfn对应于iey.sfn0_1、iey.sfn1_1、iey.sfn2_1、iey.sfn3_1，默认参数分别为3、3、3、0;
        • N4级的nXsth对应于 iey.sth1_0、iey.sth2_0、iey.sth3_0，默认参数分别为100、100、70;
        • N4级的nX2sth对应于 iey.sth1_1、iey.sth2_1、iey.sth3_1，默认参数分别为100、100、70。

        【3DNR_N4 接口与MPI接口的对应关系】

        • n4shp_ctl_mean 对应于iey.shp_ctl_mean[17]；
        • n4shp_ctl_dir 对应于iey.shp_ctl_dir[17]；
        • n4sf_bld 对应于iey.sf_bld[17]。

        【说明】

        3DNR空域滤波参数。

        【定义】

        typedef struct { 
    td_u8 sfs1, sfs2, sfs4, sfs5;
    td_u8 sbr1, sbr2, sbr4;
    td_u8 sft2, sft4;
    td_u8 strf3, strf4, strb3, strb4;
    td_u16 bld6;
    td_u16 sth1_0, sth2_0, sth3_0, sth1_1, sth2_1, sth3_1;
    td_u16 sfn0_0, sfn1_0, sfn2_0, sfn3_0, sfn0_1, sfn1_1, sfn2_1, sfn3_1;

} ot_nr_v2_sfy;

        【成员】

        成员名称

        描述

        sfs1, sfs2, sfs4, sfs5

        表示1~5号滤波器强度（N1级的3号4号滤波器强度均由sfs4控制，N2、N3级3号滤波器由strf3, strf4, strb3, strb4控制，5号滤波器仅在N2级有效）。

        取值范围：[0, 255]

        sbr1, sbr2, sbr4

        表示1、2、4号滤波器的滤波的不对称强度。

        取值范围：[0, 255]

        sft2, sft4

        表示2~4号滤波器附加强度。

        取值范围：[0, 255]

        strf3, strf4, strb3, strb4

        表示3号、4号滤波器前景以及背景的滤波强度（仅N2、N3级生效）。

        取值范围：[0, 31]

        bld6

        表示sfn6_0和sfn6_1滤波结果的混合比例（仅N1级生效）。

        取值范围：[0,16]

        sth1_0, sth2_0, sth3_0, sth1_1, sth2_1, sth3_1

        运动前景和背景区域的保边阈值。根据阈值选择使用不同的滤波器，需要配合sfn使用。

        取值范围：[0, 511]

        sfn0_0, sfn1_0, sfn2_0, sfn3_0, sfn0_1, sfn1_1, sfn2_1, sfn3_1

        根据sth保边阈值，不同图像特性选择不同滤波器的类型（滤波器号）。

        取值范围：[0, 8]

        sfn6_0, sfn6_1, sfn7_0, sfn7_1, sfn8_0, sfn8_1

        表示6号、7号、8号滤波器的混合选择（滤波器号）。

        取值范围：[0, 5]

        ot_nr_v2_mdy

        【说明】

        3DNR运动检测参数。

        【定义】

        typedef struct { 
    td_u16 math0, math1;
    td_u16 mate0, mate1;
    td_u8 mabw0, mabw1;
} ot_nr_v2_mdy;

        【成员】

        成员名称

        描述

        • N1级的mXmabw对应于 mdy[0].mabw1，默认参数为9；
        • N2级的mXmath对应于 mdy[1].math0、mdy[1].math1，默认参数分别为200、200；

        成员名称

        描述

        tfs

        表示预时域处理的时域滤波强度。

        空域滤波器参数说明

        N1~N3级包含0~5号基础空域滤波器，即nXsf0、nXsf1、nXsf2、nXsf3、nXsf4、nXsf5。不同的基础滤波器有不同的特性，nXsf1和nXsf2主要针对冲击噪点的去除，但保边能力较弱。而nXsf3~ nXsf5有较强的保边能力。可根据不同的图像特性灵活使用。（注：nX**参数里面的X均指级数，代指第n级。）

        • [nXsf0]零号滤波器为该级输入的原始像素。

        • [nXsf1][nXsf2]分别用于调试1号，2号滤波器。

          1号和2号滤波器[nXsf1][nXsf2]的特点对于图像强边缘的去噪能力较强，可以去除冲击噪点，但是对于平坦区域的去噪能力较弱（相对于nXsf3~ nXsf5滤波器，平坦区域的颗粒感强一些），1，2号滤波器效果类似，但2号的滤波强度更强一些。

        时域接口参数说明

        每一级均包含了时域的信息用于图像处理。N1、N2级的时域可采用分层处理结构（第0层、第1层和第2层），其中每个时域的接口都有三套分别对应于三层（如果接口有多个参数，接口带上后缀0,1,2来区分层级）。

        • [ref]：该接口表示参考帧开关。ref 为时域参考的总开关。

          • 设置为0时参考帧不载入，时域滤波无效；
          • 设置为1时，时域滤波参数才能生效。

        • [pretfs]：N0级时域滤波强度。利用premath和premathd动静判断信息，在N1级运行前进行时域滤波。取值范围：[0, 15]。

          注意：tfs1、tfs2和pretfs不宜同时设置过大，否则可能导致背景噪声无法有效去除的效果。math0调较小时，tfs0不宜设置过大，否则可能出现拖尾现象。

        • [mXmate]：表示平坦区域运动检测指数，其值越大，被平坦运动检测单元判定为“静止”的像素越多，因而被实施时域滤波的像素也越多，画面当然也越安静；一般需要先将math调试到合适，再微调mate，以平衡雨点噪声和运动拖尾为合适，其取值范围为[0, 8]。

        • [mXmabw]：运动检测内容窗口大小的选择，主要配合math使用，值越大，窗口越大。当在低照度下math调大还不能抑制雨点，建议将mabw调试到7以上，从而可以减轻math抑制雨点的负担，降低时域滤波的副作用。其取值范围为[5, 9]。
        • [tfs_mode]：静止区域的计算模式的选择。当该值设置为0时，静止区域为premath和math1共同决定，此时可参照[mXmath]须知对静止区域调整。当该值设置为1时，静止区域仅由math1决定，此时tfs2与tss2失效。

        • [nXtss]：值越大静止区域越光滑，但静止区域图像内容可能越模糊。取值范围为[0,31]。该参数的两个值表示分别作用不同区域。

          • 如果采取分区处理模式，可以适当调大第一个参数，作用于在运动相对不明显的区域防止前景的虚化问题。第二个参数作用于背景。
          • 当tss0表示math0决定的前景区域的空域强度，tss1表示math1决定的背景区域的空域强度，tss2表示premath决定的背景区域的空域强度。
          • 在NORM模式中，N2级仅支持空域滤波，空域滤波整体强度由tss0控制。

        • [nXtfs]：时域滤波强度，当前滤波区域使用时域时，此参数表示时域作用强度，值越大强度越大。该接口的取值范围是[0, 15]。tfs0表示math0决定的前景区域的时域强度，tfs1表示math1决定的背景区域的时域强度，tfs2表示premath决定的背景区域的时域强度。（math1和premath的背景选择可以参考mXmath接口）。注意：前景的tfs0和math0不宜过强，容易产生拖尾或者毛刺等副作用。

          建议tss1与tss2设置一样的数值，tfs1和tfs2设置一样的数值，可较好地调节背景强度。

        色度去噪参数说明

        色度去噪分为两级，NRc0和NRc1，开关为nCen。NRc0为时空域处理；NRc1为空域处理。

        • [nC0mode]：该接口表示NRc0的模式选择。当nC0mode为0时，NRc0仅使用时域去噪（NRc0中仅有tfs参数生效）。当nC0mode为1时，NRc0使用旧接口（NRc0中的tfs、sfc、tfc、trc均生效），但此时NRc1中空域滤波器sfs2无效。

        • [nCtfs]：该接口为NRc0级的时域去噪强度。取值范围：[0, 15]

          图 1 nCtfs=4调试效果图

          图 2 nCtfs=15调试效果图

          从图1和图2可以发现nCtfs调试越大，去色噪能力越强，同时颜色也会有一定的损失。

        • [sfc]：表示3DNR去色噪的第0级的空域滤波的混合强度，取值范围：[0, 255]。调试越大，画面去低频的色噪能力越强，对整体画面的颜色损失就越大。

        • [tfc]：表示3DNR去色噪的时域滤波混合强度，取值范围：[0, 63]。该参数调试去色噪强度（如图3所示），调试过程中，需权衡色噪的去除程度与色彩拖尾和画面色调变化。

          • 在[0, 16]时，随着tfc增大，去色噪越强；
          • 在[17, 48]时，随着tfc增大，去色噪会变弱；
          • 在[49, 63]时，随着tfc增大，去色噪越强。

          图 3 TFC参数控制去色噪强度图

        • [trc]：时域强度参数，用于抑制运动区域的色噪，但调大容易发生色彩浸染现象。

        • [nc0tfs_mot]：该接口为控制时域处理的前景背景区域去噪强度，横坐标表示运动强度（强度为0则为静止区域），纵坐标表示去噪强度。一般情况下，时域处理主要作用于背景区域，因此曲线设置一般为左边高右边低，否则有可能会出现颜色拖尾的现象。
        • [nCen]：该接口表示色度去噪的总开关。
        • [nc1_pre_sfs]：该接口为NRc1级的预滤波器去噪强度，去噪处理作用于全局。取值范围：[0, 16]。在某些偏色场景下，该参数变化可能不线性。
        • [nCsfs1]：该接口为NRc1级的1号滤波器去噪强度，可与曲线nc1sfs1_mot配合使用。取值范围：[0, 255]。
        • [sfs2_c_f]：该接口为NRc1级的2号滤波器前景补充去噪强度。参数sfs2_c_f的变化对效果的影响并非是线性变化的。sfs2_c_f 参数是在sfs2_c 参数的基础上对前景再调节降噪强弱。当sfs2_c较小时，sfs2_c_f在低数值调整，对前景降噪无法再减弱，可能会出现效果不变的情况。同理，在sfs2_c较大时，sfs2_c_f在高数值调整，对前景降噪无法再加强，也可能会出现效果不变的情况。取值范围：[0, 31]。
        • [sfs2_mode]：该接口为色度2号滤波器调整强度的模式选择。当该值为0时，sfs2_c接口生效，可通过调整该数值粗略地改变去噪强度，此时sfs2_sat失效；当该值为1时，sfs2_sat接口生效，可通过调整该曲线精细地改变去噪强度，此时sfs2_c失效。
        • [sfs2_c]：该接口为NRc1级的2号滤波器总体去噪强度。取值范围：[0, 31]。若sfs2_c调0，则调整sfs2_c_f无效，若sfs2_c调大，则调整sfs2_c_f可进一步调整前景区域去噪强度。整体的强度不宜调的过大，否则可能会出现颜色晕出以及颜色损失的现象。
        • [nc1sfs2_sat]：该曲线可根据饱和度精细调整去噪强度，横坐标为饱和度，纵坐标为去噪强度。取值范围：[0, 1023]。
        • [sfs2_fine_f]：该接口为NRc1级的2号滤波器前景精调去噪强度，作为[sfs2_c_f]的补充。取值范围：[0, 16]。

        • [sfs2_fine_b]：该接口为NRc1级的2号滤波器背景精调去噪强度，作为[sfs2_c_b]的补充。取值范围：[0, 16]。

          在调整好sfs2_c_f 以及sfs2_c参数的基础上，可以进一步调整sfs2_fine_f以及sfs2_fine_b对前景区域和背景区域的去噪强度分别进行调整，二者互不影响。

        • [nc1sfs2_mot]：该曲线可调整不同区域使用前景强度（sfs2_fine_f）还是背景强度（sfs2_fine_b）。横坐标为运动指数，纵坐标为使用背景强度的比例，越倾向于使用背景强度（sfs2_fine_b）的比例越高。

        • [nc1sfs1_mot]：该接口为控制sfs1空域滤波器的前景背景区域去噪强度，横坐标表示运动强度（强度为0则为静止区域），纵坐标表示去噪强度。一般情况下，空域处理主要作用于前景区域（背景区域具有时域去噪），因此曲线设置一般为左边低右边高，否则有可能会对背景的颜色造成损伤。

          须知：
          色度去噪中使用的运动判决均由NRc0级的运动判决决定。

        后处理参数说明

        后处理可以分别对亮度（gamma）以及饱和度（Ca）进行调整。

        • [gamma_en]：该接口为后gamma 的开关，该开关依赖于N4级开关，即在N4级开时，后处理才生效。
        • [post_gamma_lut]：该接口为调整的gamma曲线。横坐标与纵坐标均为亮度，取值范围为[0,255]。
        • [ca_en]：该接口为后ca的开关。
        • [post_ca_lut]：该接口为调整的ca曲线。横坐标为饱和度，纵坐标为增强的强度（32为不改变饱和度，小于32为衰减，大于32为增强），取值范围：[0, 63]。

        典型场景下的3DNR接口调试指南

        与之前芯片调优类似，主要依赖时域去噪，空域去噪作为补充。和之前主要区别在于亮度去噪和色度去噪的第零级支持时域处理，可以与BNR配合调试动静判决和时域降噪。

        图 1 3DNR调试总体流程

        1. 调整时域参数，抑制背景画面噪声，使背景区域安静，同时抑制运动区域出现拖尾效应。

          • 调试3DNR N0级，调大pretfs。同时可适当调试premath、premathd、premabw以及pretdz，初步控制背景噪声，运动没有拖尾现象。此外，还可以精细调整N0级tfs_mot曲线来抑制拖尾的现象。
          • 接着配合调试整体时域强度。N1、N2的第0,1层可以分别作为前景层和背景层。调试背景层的mXmath1，以抑制背景画面的雨点噪声为合适程度。然后调试前景层的mXmath0, 控制一部分前景运动的噪声。
          • 调试第一级的n1tfs以抑制画面的整体噪声水平为合适，需要兼顾时域去噪效果和画面运动的拖尾；通常前景层的tfs需要调的比背景小，防止运动物体的拖尾现象。
          • 调试第二级的m2math 和 n2tfs，控制整体噪声的安静水平和噪声的幅度。第二级的m2math通常要比第一级的m1math配置的小，来防止拖尾现象。
          • 若拖尾现象比较严重，可调小mXtfs0（减少前景使用的时域强度），或者调小mXmath（减少运动边缘被判定为背景的区域），同时也可以调整tfr0和tfr1减少拖尾现象。
          • 低照度下，为了减轻math的负担，可以适当调试mabw参数，极低照度下，可以适当调试mate参数来获得画面整体噪声的抑制。

          具体如图2所示。

          图 2 3DNR时域部分调试流程图

        2. 调整空域参数，进一步抑制背景雨点噪声，同时保留背景区域细节。

          • 对于背景区域，主要利用时域进行去噪，空域进行补充去噪。在低噪度下，时域背景中仍可能出现较严重的雨点噪声，此时可以增强nXtss1，同时配合nX2sfn以及nX2sth对不同背景区域进行不同强度的去噪。
          • 对于N1、N2级的分层模式，可以通过调高前景层的n1tss0在前景层混入一定比例的空域滤波结果，来增强运动物体的去噪效果。
          • 根据nX2sfn与nX2sth来调整背景不同区域使用不同强度的滤波器。N2中的3号、4号和5号滤波器均可根据3DNR_n2中的曲线进行不同区域不同强度的调整。
          • 建议操作步骤为，先调大基础滤波器的去噪强度以及nXtss1，调整nXsfn为0号滤波器和基础滤波器的组合，再调整nX2sth的数值，找出不同阈值控制的区域。对不同区域选择适合的滤波器，最后再调整滤波器强度以及tss1到适合，以及对3DNR_n2中的曲线进行精调，尽可能保留背景区域细节信息。
          • 以同样的方法调整N3级的背景空域参数，作为N2级去噪结果的补充。

        3. 调整空域参数，抑制前景噪声，同时保留前景细节。

          • 调试N2、N3的空域参数，每一级均可以分开前景和背景，分别调试空域效果。可以调试6、7、8号滤波器作为混合滤波器。根据当前噪声特性，通过调节基础滤波器的混合权重，做到尽量不损失细节的前提下压低噪声。
          • 建议运动区域主要利用N2级的空域滤波器组合进行去噪，前景区域利用5号滤波器压制爆点噪声和强边缘噪声，同时配合3号滤波器（例如使用6号混合滤波器对5号和3号滤波器进行混合）在压制噪声的同时保留更多细节。前景区域可以通过Coring的功能保留细节合入细碎噪声。再利用N3级的3号和4号滤波器对噪声做进一步的压制处理。前景区域的处理，可以通过曲线的调节来达到细节、边缘和噪声平衡的强度。在低噪度的情况下，可以通过Coring保留一定的细碎噪声和细节，让图像更加自然。
          • 以同样的方法调整N3级的前景空域参数，作为N2级去噪结果的补充。

        4. 最后一级为增强滤波器，就是post sharpen，用来进行细节增强的。该级可以对静止区域和运动区域分开调试，分别配置不同的增强参数。

        5. 在亮噪调试合理的基础上，最后调试色度去噪NRc接口。

          打开Nc0中的tfs进行时域去噪，同时调整3DNR_nc中的nctfsMot，一般曲线左端数值调整更大，右端数值更小，目的是让静止区域尽可能使用时域滤波，同时减少运动区域使用时域滤波，防止出现色度的拖尾现象。

        6. 调试色噪N1级参数，进一步减少色噪。

          先调整presfs减少色噪的大小。再调整ncsfs1以及sfs2进行色噪去除。ncsfs1可配合3DNR_nc中的ncsfs1Mot控制sfs1空域去噪的区域，一般曲线左端数值较大，右端数值较小，目的是尽可能减少静止区域使用空域去噪，空域去噪有可能对小块颜色造成损伤。若sfs1仍不能满足去噪效果，可接着调试sfs2，先调整整体强度sfs2_c，再在此基础上调整前景的强度sfs2_c_f。若此时颜色损失比较严重，可以分别减小sfs2_fine_f和sfs2_fine_b，减小sfs2对前景和背景区域的损伤。若需要更加精细地对不同区域使用不同的去噪强度，可调整sfs2_mot曲线进行前景区域和背景区域的区分，或者调整sfs2_sat曲线控制不同饱和度的去噪强度。

        调试3dnr过程中常见问题解答

        1. 调节基础滤波器强度，图像效果不明显？

          答：应在sfn参数中选择调节的滤波器号，同时调整对应通路的tss的强度。

        2. 调节tfs2和tss2效果不明显？

          答：当math1调节较大时，背景区域由math1决定的区域为主，此时调节tfs1和tss1可达到调整背景的效果。若希望使用tfs2和tss2来调整背景，需将math1尽可能调小，甚至调为0。

        3. 发现ISP其他模块的参数或3dnr中的空域参数调节改变过大时，图像会出现延时反应？

          答：可以查看3dnr中的时域强度参数：亮度相关的可以查看pretfs、nXtfs。色度相关的可以查看nctfs。若上述参数过大时，可适当调小上述参数，此时图像延时反应现象会有所减弱。

        4. 使用混合滤波器时，调整混合选择的滤波器强度，图像效果不明显？

          答：除了问题1的方法外，还需要检查曲线sf_bld，查看调整的滤波器混合比例是否过小。

        5. 增加时域强度，背景去噪效果反而更差？

          答：检查调整的时域强度是否过强，时域强化过强，可能会导致信息无法更新，去噪效果变差。此时调小时域强度，可能去噪效果更好。

          注意：3dnr具有N0、N1、N2三级时域去噪，同时调得过大就可能出现该问题。

        6. Norm模式下，N2级不生效？

          答：Norm模式下，N2级时域不生效，仅空域滤波器生效，此时tss0控制空域滤波器的整体强度，可调大tss0，查看N2是否生效。

        7. sharpen、3dnr中均具有运动区域（前景区域）和静止区域（背景区域）分别使用不同强度的能力。若运动区域和静止区域增益或去噪强度差异较大时，可能会出现画面部分区域清晰和模糊跳变的情况。

          答：该现象出现的原因：运动map计算不够准确，部分静止区域有时被认为是静止区域，有时被认为是运动区域。此时运动区域和静止区域的处理差异较大，则会出现部分区域时而清晰时而模糊。因此缓解该现象可以通过调整运动map（调大BNR中md_static_ratio、md_motion_ratio、md_static_fine_strength以及3dnr X中premath、premathd、pretdz等参数，使得被误判为运动区域的静止区域被判定为静止区域）；或通过减少运动区域和静止区域的处理差异；或调整3dnr Attr中的n2sf_mot、n3sf_mot（亮噪相关）和nc0tfs_mot、nc1sfs1_mot、nc1sfs2_mot（色噪相关），使得运动区域和静止区域过度平滑。

        8. pretfs调0后，调整premath、premathd、pretdz等参数也会对图像效果造成影响。

          答：不仅pretfs使用了premath等参数控制的运动map，在N1、N2、N3、N4级中也都使用了premath等参数控制的运动map，所以即使pretfs调0，再调整这些参数也会影响到图像效果。
