        概述

        VGS是视频图形子系统，全称为Video Graphics Sub-System。支持对一幅输入图像进行处理，如进行Crop、缩放、像素格式转换、视频存储格式转换、压缩/解压、Cover、OSD、Mosaic、画线、旋转、亮度和统计、Corner_rect、拼接、Border、Aspect Ratio、Mirror/Flip等处理。

        基本概念

        • job

          VGS管理task的结构，一个job里可以包含多个task，VGS保证task按照添加到job的顺序执行，并且保证一个job里的所有task一次性提交硬件执行。用户可以在加载VGS ko时设置模块参数（g_max_vgs_job）来设置VGS支持的最大job数。job数取值范围为[OT_VGS_MIN_JOB_NUM，OT_VGS_MAX_JOB_NUM]，默认为OT_VGS_DEFAULT_JOB_NUM。

        • task

          对一幅图像完成具体的一个或多个操作，比如叠加OSD、缩放或像素格式转换等。用户可以在加载VGS ko时设置模块参数（g_max_vgs_task）来设置VGS支持的最大task数。task数取值范围为[OT_VGS_MIN_TASK_NUM，OT_VGS_MAX_TASK_NUM]，默认为OT_VGS_DEFAULT_TASK_NUM。

        • node

          VGS硬件的最小执行单位，一个task对应一个或多个node。node中包含硬件工作需要的信息，比如源图像地址，目标图像地址，操作类型等，并按照硬件要求的形式组织。用户可以在加载VGS ko时设置模块参数（g_max_vgs_node）来设置VGS支持的最大node数。node数取值范围为[OT_VGS_MIN_NODE_NUM，OT_VGS_MAX_NODE_NUM]，默认为OT_VGS_DEFAULT_NODE_NUM。

        • handle

          任务句柄，标识一个job。

        • 在垂直分块场景下，handle最大数量不受g_max_vgs_job限制，而是通过模块参数（g_max_vgs_ver_split_handle）进行配置。vgs_ver_split_handle取值范围[2,10]，默认为5。

        说明：
        加载ko并配置模块参数命令示例：insmod ot_vgs.ko g_max_vgs_job=64 g_max_vgs_task=100 g_max_vgs_node=100 g_max_vgs_ver_split_handle=5

        功能描述

        VGS的功能主要有Crop、缩放、OSD、Cover、Mosaic、画线、像素格式转换、视频存储格式转换、压缩/解压、旋转、亮度和统计、Corner_rect、拼接、Aspect Ratio、Border、Mirror/Flip。

        • Crop

          VGS支持从图像中裁剪指定区域。

        • 缩放

          VGS支持对一幅图像进行缩放，最大支持图像宽高均放大16倍，最大支持图像宽高均缩小30倍。支持单分量（Y）缩放。

        • OSD

          VGS支持在一幅图像上叠加一张位图，可设置位图是否反色，支持批量叠加OSD。

          须知：
          批量叠加OSD时，内部是通过提交多个task来实现，每个task使用上一个task叠加完OSD的图像作为当前task的源图像进行OSD处理。

        • Cover

          VGS支持对一幅图像进行遮挡操作，遮挡区域形状可以是矩形或者任意四边形，遮挡区域颜色为纯色，支持批量叠加Cover。

          须知：
          批量叠加Cover时，内部是通过提交多个task来实现，每个task使用上一个task叠加完Cover的图像作为当前task的源图像进行Cover处理。

        • Mosaic

          VGS支持对一幅图像进行叠加Mosaic操作，Mosaic块大小有8x8、16x16、32x32、64x64四种选择，Mosaic区域形状为矩形，每个Mosaic块为纯色，支持批量叠加Mosaic。

          须知：
          批量叠加Mosaic时，内部是通过提交多个task来实现，每个task使用上一个task叠加完Mosaic的图像作为当前task的源图像进行Mosaic处理。

        • Corner_rect

          VGS支持对一幅图像进行叠加Corner_rect操作，Corner_rect类型有角框和实线框，支持批量叠加Corner_rect。

          须知：
          - 批量叠加Corner_rect时，内部是通过提交多个task来实现，每个task使用上一个task叠加完Corner_rect的图像作为当前task的源图像进行打Corner_rect处理。
          - 批量叠加Corner_rect时，每个Corner_rect颜色和类型是一样的。

        • 拼接

          VGS支持对最多4幅图像进行水平拼接操作，图像数量可设置。

          须知：
          拼接输入的图像的宽高、像素格式、视频存储格式、压缩类型等信息需要保持一致。不支持对紧凑段压缩图像进行拼接。

        • 画线

          VGS支持对一幅图像进行画线操作，支持批量画线。

          须知：
          - 画线操作时，如果起始坐标和结束坐标的X坐标相同，则起始坐标和结束坐标的Y坐标不变，X坐标分别向右增加线的宽度。
          - 画线操作时，如果起始坐标和结束坐标的X坐标不相同，则X坐标不变，起始坐标与结束坐标的Y坐标分别向下方延伸线的宽度（即X坐标不变，Y坐标向下增加线宽）。

        • 像素格式转换

          VGS支持的输入输出像素格式包括semi-planar 420、semi-planar 422、package 422和单分量（Y）。支持semi-planar 420与semi-planar 422之间的格式转换，支持semi-planar 420、semi-planar 422到单分量（Y）格式的转换，做像素格式转换时，支持UV先后顺序可调整。

        • 视频存储格式转换

          VGS支持linear、tile64x16和tile32x4格式。

        • 压缩/解压

          VGS支持linear格式下semi-planar 422、semi-planar 420和单分量（Y）格式的压缩/解压。

        • 亮度和统计

          统计图像的指定区域亮度信息之和。支持批量统计。

        • 旋转

          VGS支持0、90、180和270度的旋转。

        • Aspect Ratio

          幅形比，指定输出画面相对于输入画面的宽高纵横比。

        • Border

          边框，指定输出画面四边覆盖边框。

        • Mirror/Flip

          Mirror即水平镜像，Flip即上下翻转。可使用Mirror+Flip实现180°旋转。

        注意：

        1、要进行Mosaic处理时，输入图像宽度不能小于64。

        输出图像分辨率及对齐要求

        1、最小支持：4x4。

        2、最大支持：16384x8192。

        3、宽度和高度均为2像素对齐。

        4、非压缩时，linear格式帧起始地址2对齐，stride 16对齐。

        5、压缩时，linear格式压缩头地址16对齐。header_stride 在帧宽度不大于4096时16对齐，帧宽度大于4096且不大于8192时32对齐，帧宽度大于8192时64对齐；帧起始地址16对齐，stride 16对齐。

        【说明】

        定义VGS画线操作的相关配置。

        【定义】

    ot_point                   end_point;

    td_u32                     color;                
} ot_vgs_line;

        【成员】

        成员名称

        描述

        start_point

        线的起始点坐标。坐标值均要求2对齐，取值范围：

        Hi3519DV500和Hi3511CV100：

        水平位置X：[-16384, 16382]

        垂直位置Y：[-8192, 8190]

        Hi3516CV610:

        水平位置X：[-4096, 4094]

        垂直位置Y：[-4096, 4094]

        end_point

        线的结束点坐标。坐标值均要求2对齐，取值范围：

        Hi3519DV500和Hi3511CV100：

        水平位置X：[-16384, 16384]

        垂直位置Y：[-8192, 8192]

        Hi3516CV610:

        水平位置X：[-4096, 4096]

        垂直位置Y：[-4096, 4096]

        thick

        线的宽度，2像素对齐。

        取值范围：[2,16]

        color

        线的颜色，RGB888格式，取值范围：[0x0, 0xFFFFFF]

        【注意事项】

        • 画线可以部分或者全部超出目标图像。

        • 画线颜色为RGB模式，R、G、B分别对应位域如下：

          31 23 15 7 0

          |--------------|--------R------|--------G------|--------B------|
