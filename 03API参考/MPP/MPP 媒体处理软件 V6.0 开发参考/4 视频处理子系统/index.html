        概述

        VPSS是视频处理子系统。支持对输入图像进行统一预处理，如去噪、去隔行、裁剪等，然后再对各通道分别进行处理，如缩放、加边框等。

        支持的具体图像处理功能包括FRC、Crop、3DNR、DEI、IE、LDCI、DCI、LTI/CTI、Cover/CoverEx、Overlay/OverlayEx、Mosaic/MosaicEx、Corner_rect/Corner_rectEx、LineEx、Scale、固定角度旋转、任意角度旋转、鱼眼矫正、LDC、展宽、PMF、FOV、LUT、拼接、获取区域亮度和、低延时、Mirror/Flip、Aspect Ratio、Border、像素格式转换、压缩解压等。

        说明：
        上述功能仅描述所有方案中存在的功能，不代表每个方案都包含所有功能。其中的英文缩写请参照“缩略语”章节描述。

        基本概念

        • Group

          • VPSS对用户提供组（Group）的概念。最大个数请参考OT_VPSS_MAX_GRP_NUM定义，各Group分时复用VPSS硬件，硬件依次处理各个组提交的任务。
          • 如果用到的VPSS Group数量超过128个，则需要修改/etc/profile，在其末尾加上ulimit -HSn 4096，指定系统同时最大可打开文件数为4096。

        • Pipe

          VPSS组的输入通道，非拼接场景使用Pipe0，拼接场景其他通道可接收多路数据进行拼接。

        • Channel

          VPSS组的输出通道。一个VPSS组提供多个通道，每个通道具有缩放等功能。

        • FRC

          帧率控制分为两种：组帧率控制和通道帧率控制。

          • 组帧率控制：用于控制各Group对输入图像的接收。
          • 通道帧率控制：用于控制各个通道图像的处理。

          当VPSS前端绑定的是VI模块时，组上帧率控制使用的是根据time_ref做补偿的帧率控制算法，先还原VI原始帧率再做帧率控制，绑定的是其他模块时，组上帧率控制不考虑time_ref，直接按比例做帧率控制。VPSS通道帧率控制不考虑time_ref。VPSS帧率控制只能减帧，不能增帧。

        • Crop

          从图像中裁剪指定区域。裁剪类型分为绝对坐标裁剪和相对比例裁剪。

          • 组裁剪，对输入图像做裁剪；
          • 物理通道裁剪，对物理通道图像做裁剪；
          • 扩展通道裁剪，对扩展通道图像做裁剪。

        • DEI

          将交错的隔行视频源还原成逐行视频源。

        • 3DNR

          3D降噪。通过参数配置，把图像中的高斯噪声去除，使得图像变得平滑，有助于降低编码码率。

        • IE

          图像增强。

        • LDCI

          基于局域直方图均衡的方法来增强局部的对比度，提升暗区细节，同时对图像中高频进行一定的增强，提升对比度。

        • DCI

          对图像进行动态的对比度调节，即在增强图像暗区亮度时不使亮区过亮，或降低亮区亮度时不使暗区过暗。

        • LTI/CTI

          图像锐化(Sharpen)。锐化图像的边缘和凸显图像细节，对经过缩放（Scale）后的图像进行频率补偿或增强，使得图像边缘锐利，轮廓清晰。

        • Scale

          缩放，对图像进行缩小放大。缩放倍数指水平、垂直各缩放多少倍。

        • Mirror/Flip

          Mirror即水平镜像，Flip即上下翻转。可使用Mirror+Flip实现180°旋转。

        • Mosaic

          • 马赛克，对VPSS输出图像在指定区域填充马赛克块。
          • 马赛克区域宽度要求4像素对齐，马赛克区域部分超出图像时，水平方向软件会自适应向下4对齐裁剪掉超出部分。

        • MosaicEx

          马赛克，调用VGS对VPSS物理通道的输出图像指定区域填充马赛克块。

        • Cover

          • 视频遮挡区域，对VPSS的输出图像填充纯色块或空心边框。
          • 遮挡区域坐标类型分为绝对坐标遮挡和相对坐标比例遮挡。相对坐标的计算是相对输入图像。

        • CoverEx

          • 视频遮挡区域，调用VGS对VPSS物理通道的输出图像填充纯色块或空心边框。
          • 遮挡区域坐标类型分为绝对坐标遮挡和相对坐标比例遮挡。相对坐标的计算是相对输入图像，不是通道图像，效果与Cover相对坐标类似。

          注意：当设置相对坐标比例遮挡时，仅在接口处检查相对坐标参数，由于输入图像宽高变化无法预测，因此不保证最终遮挡区域配置参数始终有效。

        • Overlay

          视频叠加区域(OSD)，对VPSS输出图像叠加位图。

        • OverlayEx

          视频叠加区域，调用VGS对VPSS物理通道的输出图像叠加位图。

        • LineEx

          调用VGS对VPSS物理通道的输出图像画线。

        • Corner_rect

          在VPSS的输出图像上打角框/实线框。

        • Corner_rectEx

          物理通道支持调用VGS在图像上打角框/实线框。

        • 获取区域亮度和

          获取输入图像或物理通道输出图像指定区域亮度和。

        • 鱼眼矫正

          支持对图像做鱼眼矫正，支持鱼眼多宫格处理。

        • LDC

          对图像做镜头畸变矫正。

        • 展宽

          支持对图像做展宽处理。

        • PMF

          根据PMF矩阵对图像进行映射变换。

        • FOV

          根据视场角矩阵对图像进行相应视场角矫正。

        • LUT

          根据查找表对图像进行相应变化，可融合两张LUT或串联两张LUT，也可一张LUT与其他GDC功能组合。

        • 拼接

          支持对多路输入进行横向的硬拼或融合拼接。

        • 低延时

          • 输入低延时，接收前端模块发送的低延时帧；
          • 输出低延时，通道向后端模块发送低延时帧。

        • 固定角度旋转

          物理通道支持0度、90度、180度以及270度固定角度的旋转功能。

        • 任意角度旋转

          任意角度旋转功能。

        • Aspect Ratio

          幅形比，指定输出画面相对于输入画面的宽高纵横比。

        • Border

          边框，VPSS在输出图像加边框。

        • 工作模式

          VPSS工作模式，分为在线、离线等模式。详见“系统控制”章节。

        • 压缩/解压

          • 支持通道输出图像进行压缩；支持对输入压缩图像解压；
          • 支持3DNR参考帧压缩/解压；
          • 紧凑段压缩、参考帧压缩可节省内存，其它压缩不节省内存。所有压缩都能改善带宽占用。

        • 像素格式转换

          支持设置输出图像的像素格式。

        • 备份节点

          原始图像的备份节点。每个Group都有一个备份节点，用于备份即将提交硬件处理的原始图像。VPSS在以下情况会将缓存队列头节点的图像放入备份节点：

          • 当原始图像要经过VPSS 硬件处理时，VPSS 会将其放入备份节点，并替换掉原有备份的图像。
          • 当后端绑定的接收模块要求VPSS 将队头图像放入备份节点时，VPSS 也会替换备份节点中的图像，即使该图像不经过硬件处理。

        • 分块

          图像超过特定宽度时，分块处理。相应资源数在模块参数中设定。资源数设定需要大于等于实际需要的数量。

        • FMU

          支持使用帧存管理单元管理帧存数据，降低媒体数据内存占用，降低端到端延时。

        须知：
        - Hi3519DV500/Hi3511CV100 Cover、Mosaic、Corner_rect可配置到Group上，所有通道效果相同，也可配置到某个通道上(Cover、Mosaic、Corner_rect都需要在该通道上)，其他通道无效果。
        - Hi3519DV500/Hi3516CV610/Hi3511CV100 Cover、Mosaic、Corner_rect存在两种或以上类型时，按Mosaic、Cover、Corner_rect的先后顺序处理，即先处理的类型如果和后处理的类型出现重叠，则后处理的类型会覆盖先处理的类型。
        - Hi3519DV500/Hi3511CV100打Cover、Mosaic、Corner_rect时总个数不超过12个。
        - Hi3519DV500/Hi3511CV100当输入图像宽度不超过4096，并且输出通道宽度超过4096时，若Mosaic的有效块大小为8x8，则配置到该通道上的所有Mosaic都不生效。
        - Hi3511CV100当输入图像宽度不超过4096，并且输出通道宽度超过8192时，若Mosaic的有效块大小为16x16，则配置到该通道上的所有Mosaic都不生效。
        - Hi3519DV500/Hi3511CV100同一时刻仅允许有一个通道放大；当一个通道进行semi-planar 420转semi-planar 422时，其它通道不能再放大。
        - Hi3519DV500/Hi3511CV100输入图像宽度超过4096时分块。
        - Hi3516CV610支持在Group上配置Cover，总个数不超过8个。
        - Hi3516CV610支持在物理通道0和1上同时配置Cover、Corner_rect，单个物理通道上打Cover、Corner_rect的总个数不超过4个。
        - Hi3516CV610仅支持物理通道0进行放大。
        - Hi3516CV610输入图像宽度超过3200时分块。

        图 1 VPSS上下文关系

        通过调用SYS模块的绑定接口，可与VPSS/USER/VDEC/VI和VO/VENC/SVP等模块进行绑定，其中前者为VPSS的输入源，后者为VPSS的接收者。用户可通过MPI接口对Group进行管理。每个Group除拼接场景外仅可与一个输入源绑定。

        Group的物理通道有两种工作模式：AUTO和USER，两种模式间可动态切换。AUTO模式下各通道仅可与一个接收者绑定，主要用于预览和回放场景下做播放控制。USER模式下各通道可与多个接收者绑定。

        需要特别注意：USER模式主要用于对同一通道图像进行多路编码的场景，此模式下播放控制不生效，因此回放场景下不建议使用USER模式。VPSS只有工作在离线模式下才支持AUTO模式。如果绑定VENC使用FMU，在开启OT_VPSS_DIRECT_CHN通道或WRAP通道时，OT_VPSS_CHN0也不支持AUTO模式。

          • 只有USER模式的通道支持；

          • 使能此功能后，调用获取组亮度和接口获取的亮度和可能不准确，建议不要获取组亮度和。
          • VI 插入用户图片场景下，由于用户图片VB 是一块固定的VB，如果VPSS 使能此功能后会导致用户图片VB 被频繁改写，此时VPSS 组不要开启Crop、IE 功能，并且输出通道不要开启压缩、缩放等。
          • 输入输出复用buffer会对输入图像进行改写，场景上需要考虑改写影响。
          • Hi3519DV500/Hi3511CV100仅离线模式物理通道支持复用buffer。
          • Hi3519DV500/Hi3511CV100只有在输入宽高不小于输出宽高且压缩模式、像素格式、视频格式一致时才支持复用buffer。

        【说明】

        定义VPSS 写出GDC LUT配置信息。

        【定义】

        typedef struct {
    td_bool          enable;    /* RW; Range: [0, 1]; save gdc out lut or not */

} ot_vpss_out_lut_cfg;

        【成员】

        成员名称

        描述

        enable

        是否使能写出gdc lut。默认值为TD_FALSE。调用查询接口进行坐标查询时需要开启，否则可关闭以节省lut写出内存。

        buf_size

        使能写出lut时，lut内存的大小，需要足够存储写出lut数据。

        【注意事项】

        buf_size = OT_ALIGN_UP(func(out_size.width, cell_size), 32) * OT_ALIGN_UP((out_size.height + (16<<cell_size) -1)/(16<<cell_size) + 1, 32)
        • func(out_size.width, cell_size)对应的算法实现是OT_ALIGN_UP(((OT_DIV_UP(out_size.width, (16 << cell_size)) + 1) * 8), 16)。
        • out_size代表gdc每个区域输出的宽高，类型是ot_size。若gdc为多区域输出，buf_size按照实际生效的输出区域结果累加计算。例如鱼眼有两个输出区域：region0, region1，先分别计算对应的buf_size0, buf_size1, 总的大小是buf_size=buf_size0+buf_size1;
        • cell_size代表LUT精度，该变量为枚举整数类型ot_lut_cell_size，范围是[0,4]，（16<<(cell_size)）的最大值为256。
        • #define OT_ALIGN_UP(x, a) ((((x) + ((a) - 1)) / (a)) * (a))
        • #define OT_DIV_UP(x, a) (((x) + ((a) - 1)) / (a))

        ot_vpss_chn_cfg

        【说明】

        定义通道配置结构体。

        【定义】

        typedef struct {
    td_bool scale_ex_support;
    td_bool chn_proc_ex_support;
} ot_vpss_chn_cfg;

        【成员】

        成员名称

        描述

        scale_ex_support

        VPSS是否支持超过15倍缩小。默认值为TD_TRUE。

        VPSS通道最大缩小倍数是30倍，但超过15倍的情况下，会额外调用VGS做一次缩放。如果不需要30倍缩小场景，建议设置为TD_FALSE，在grp路数多的场景可降低CPU消耗。

        chn_proc_ex_support

        VPSS是否支持通道后处理。默认为TD_TRUE。通道后处理功能需要额外调用GDC/VGS等模块。如果VPSS通道在业务上不需要通道后处理功能（如：旋转、鱼眼、coverex、mosaicex、line、overlayex以及获取通道亮度和等），建议设置为TD_FALSE，在grp路数多的场景可降低CPU消耗。

        【注意事项】

        无。

        【相关数据类型及接口】

        • ss_mpi_vpss_set_chn_cfg
        • ss_mpi_vpss_get_chn_cfg
