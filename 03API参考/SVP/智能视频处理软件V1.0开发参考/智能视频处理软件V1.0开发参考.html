        概述

        智能视频处理软件（Intelligent Video Process，简称IVP）可支持智能应用软件快速开发。该软件包直接提供API接口用于检测和识别应用的快速集成开发。

        该平台支持应用软件快速开发以下功能：

        • 目标检测：人脸、人形、车辆、宠物、头肩、非机动车检测等。
        • 视觉结构化识别：人脸抓拍、车牌识别。

        系统架构

        IVP平台的典型系统层次如图1所示，主要分为以下层次：

        • SDK层：SDK提供的芯片相关的硬件处理层。
        • 智能视频处理层：基于SDK层控制芯片完成相应的视频处理任务。
        • 应用层：基于智能视频处理层，由用户开发的智能应用软件系统。

        智能视频处理软件架构

        智能视频处理软件主要数据处理流程如图1所示，主要分为目标检测（AiDetect）和视觉结构化识别（AiVsr）。主要的处理流程介绍如下：

        • AiDetect接收SDK媒体处理平台（MPP）输出的视频帧，输出目标位置信息，该结果可以直接用于周界，告警，客流统计等智能应用，或者传入AiVsr作进一步的结构化识别。
        • AiVsr接收SDK媒体处理平台（MPP）输出的视频帧，和AiDetect输出的目标位置信息，输出人脸抓拍或者车牌识别的结构化信息。

        重要概念

        • 通道（channel）

          用户在调用AiDetect API时，需要传入对应的通道号，用于表示不同的算法分析任务。

        • 检测（detect）

          AiDetect API通过对视频中画面中存在的目标（如人脸、人形、机动车等）进行检测，并获取该类目标在图像中的坐标。

        • 跟踪（track）

          AiDetect API内部会基于对已检测到的目标进行跟踪，需要该目标在画面中连续出现。当目标离开画面后，跟踪会断开。

        • 运动判断(motion detect)

          AiDetect API内部会基于对已跟踪到的目标进行运动判断，输出目标的运动状态(静止/运动)。

        • 模型（model）

          模型是针对一系列目标数据进行建模后的产物，AiDetect API内部检测流程依赖模型的检测能力。

        • 帧率（frame_rate）

          AiDetect API内部会计算最近1秒内的检测帧率、平均帧率，单位是fps，即每秒能分析多少帧。

        • 支持场景：

          • 室内：家居、办公室、楼道、商场、室内停车场等。

        API参考

        AiDetect API提供以下API：

        • ss_mpi_aidetect_create_chn：创建检测通道并设置通道的属性参数，通道的属性包含是否开启跟踪以及是否开启运动检测。
        • ss_mpi_aidetect_destroy_chn：销毁当前通道。
        • ss_mpi_aidetect_set_chn_attr：设置通道属性，包括通道对应模型的检测分类是否开启跟踪及运动状态检测，可动态配置。
        • ss_mpi_aidetect_get_chn_attr：获取通道属性，包括当前通道内的模型对应检测分类是否开启跟踪及运动检测。
        • ss_mpi_aidetect_set_chn_param：设置通道参数，包括当前通道对应模型的分类阈值、模型执行的优先级，可动态配置。
        • ss_mpi_aidetect_get_chn_param：获取通道参数，包括当前通道对应模型的阈值，模型执行的优先级。
        • ss_mpi_aidetect_get_model_info：获取模型相关信息，包括当前通道模型输入分辨率以及模型支持的检测类型。
        • ss_mpi_aidetect_process：算法分析处理，输入帧和通道，得到检测、跟踪结果。
        • ss_mpi_aidetect_set_log_level：设置日志输出级别，可动态配置。
        • ss_mpi_aidetect_get_log_level：获取当前日志级别，默认为0。

        • ss_mpi_aidetect_query_status：获取当前通道状态。

          须知：
          用户调用本模块API编译可执行程序时需要额外链接sdk基础版本的库: libsvp_acl.so, libss_mpi_cipher.so, libss_mpi_ive.so, libot_osal.so，libss_ivs_md.so。

        概述

        本文档所涉及的接口是一套完整的AI算法检测接口，用户基于AiVsr API（AI Vision Structured Recognition API，AI视觉结构化识别接口）可以快速开发人脸抓拍、车牌识别和人脸识别应用，您在开发过程中可查阅AiVsr API支持的各种参考信息，包括API、头文件、错误码等。

        功能描述

        • 重要概念

        • 功能介绍

        • 使用流程

        重要概念

        • 通道（channel）

          用户在调用AiVsr API时，需要传入对应的通道号，用于表示不同的算法分析任务，一个通道只能运行一种任务类型。

        • 人脸抓拍（face_capture）

          AiVsr API通过对视频中检测到的人脸信息进行分析，提供人脸质量和角度等属性信息。

        • 车牌识别（vlpr）

          AiVsr API通过对视频中检测到的车辆信息进行分析，提供识别到的车辆属性，车牌属性以及车牌号码。

        • 人脸识别（fr）

          AiVsr API通过对视频中检测到的人脸信息进行分析，提供人脸特征向量信息。

        功能介绍

        人脸抓拍模型

        • 支持场景：

          • 室内：家居、办公室、楼道、室内停车场等。
          • 室外：园区、街道等。

        • 使用约束：

          • 目标数量：人脸属性分析的目标个数上限是OT_FACE_CAPTURE_MAX_OUTPUT_NUM。
          • 目标角度：建议参考高度2.2-3m俯角拍摄；抓拍距离3.5-6m。

          • 目标姿态：

            人脸：支持上下遮挡少于50%（至少露出眼睛、鼻子），左右遮挡少于50%（半边脸）。

        • 目标大小：1080p分辨率下

          • 最小人脸像素大小：40*40
          • 最大人脸像素大小：400*400（人形在符合遮挡规格的约束下）

        • 支持光照：正常光照、低照。

        车牌识别模型

        • 支持场景：

          • 乡村道路，乡村主要路口。
          • 小区出入口，乡村停车场出入口。

        • 使用约束：

          • 目标数量：车牌目标个数上限是OT_VLPR_MAX_OUTPUT_NUM。
          • 目标角度：乡村道路，乡村主要路口参考高度3.5~5米，摄像机垂直角度10~30度，水平角度10~15度；小区出入口，乡村停车场出入口参考高度1.2~2米，摄像机垂直角度10~30度，水平角度10~15度。

        • 目标遮挡：车牌无遮挡。

        • 目标大小：1080p分辨率下

          • 最小车辆像素大小30*40
          • 最大车辆像素大小800*800

        • 支持光照：正常光照、低照。

        人脸识别模型

        • 支持场景：

          室内：家居、楼道等。

        • 使用约束：

          • 目标数量：人脸属性分析的目标个数上限是OT_FR_MAX_OUTPUT_NUM。
          • 目标角度：建议参考高度2.2-3m俯角拍摄。

          • 目标姿态：

            人脸：支持遮挡少于30%。

        • 目标大小：1080p分辨率下，瞳距大于20像素人脸。

        • 支持光照：正常光照。
        • 模糊程度：单帧检测物较清晰，肉眼可清晰辨识轮廓，人脸可辨识五官。

        API参考

        AiVsr提供以下API：

        • ss_mpi_aivsr_create_chn：创建aivsr通道并设置通道的属性参数。
        • ss_mpi_aivsr_destroy_chn：销毁指定通道。
        • ss_mpi_aivsr_set_chn_attr：设置通道属性，包括通道对应任务的属性参数，可动态配置。
        • ss_mpi_aivsr_get_chn_attr：获取通道属性，包括通道的任务类型以及对应任务类型的属性参数。
        • ss_mpi_aivsr_set_chn_param：设置通道参数，包括当前通道对应任务类型、模型执行的优先级，该任务类型对应的参数，可动态配置。
        • ss_mpi_aivsr_get_chn_param：获取通道参数，包括当前通道对应任务类型、模型执行的优先级，该任务类型对应的参数。
        • ss_mpi_aivsr_process：算法分析处理，输入通道、帧信息，检测结果、输出结构化属性识别结果。
        • ss_mpi_aivsr_register_result_callback：注册结果回调函数。
        • ss_mpi_aivsr_unregister_result_callback：注销结果回调函数。

        • ss_mpi_aivsr_async_process：异步算法分析处理，输入通道，帧信息，检测结果，通过结果回调函数获取结构化识别结果。

          须知：
          用户调用本模块API编译可执行程序时需要额外链接sdk基础版本的库：libsvp_acl.so、libss_mpi_cipher.so、libss_mpi_ive.so、libot_osal.so。

        ot_face_capture_param

        【说明】

        定义人脸抓拍的通道参数。

        【定义】

        typedef struct {
    td_u16 min_face_quality;
    ot_face_pose max_face_pose;
    td_u16 min_pupil_pixel_dist;
} ot_face_capture_param;

        【成员】

        成员名称

        描述

        min_face_quality

        最小人脸质量，范围：[0,100]。按照最小人脸质量过滤结果，人脸质量小于min_face_quality，则过滤该人脸。最小人脸质量为0，则不对人脸质量进行过滤。默认值30。

        max_face_pose

        最大人脸姿势，按照最大人脸姿势过滤结果，人脸姿势成员变量(如roll、yaw、pitch)的绝对值大于max_face_pose中对应成员的值，则过滤人脸。最大人脸姿势为0，则不对人脸姿势进行过滤。

        • max_face_pose.roll设置范围为[0,180]，默认值为60；
        • max_face_pose.yaw设置范围为[0,180]，默认值为90；
        • max_face_pose.pitch设置范围为[0,180]，默认值为120。

        min_pupil_pixel_dist

        最小瞳孔像素距离，相对于1920x1080图片下的像素距离。按照最小瞳孔距离过滤结果，瞳孔距离小于min_pupil_pixel_dist，则过滤人脸。最小瞳孔像素距离为0，则不过滤人脸。默认值20。

        AiDetect和AiVsr接口调用前，需提前加载ot_cipher.ko库，未加载时，会出现hash init失败问题。

        【解决】

        加载ot_cipher.ko库。

        【分析】

        检查送帧图像，发现送入检测图像有畸变。

        【解决】

        人脸抓拍送帧图像与AiDetect送帧图像分辨率不一致问题

        【现象】

        人脸抓拍人脸图像抠图失败，接口调用失败。

        【原因】

        人脸抓拍送帧图像分辨率与AiDetect送帧图像分辨率不一致，AiDetect检测框未按AiVsr送入图像的分辨率做相应的缩放处理，人脸抠图失败。

        【解决】

        人脸抓拍送帧图像与AiDetect送帧图像分辨率不一致，业务层需对AiDetect检测到的检测框按AiVsr送入图像的分辨率做相应的缩放处理，保证在输入分辨率图像下的检测框正确。

        人脸抓拍人脸重复率高

        【现象】

        人脸抓拍上报人脸重复率高。

        【分析】

        人脸检测跟踪ID出现跳变，检查人脸检测送帧帧率稳定连续。送帧帧率较低，平均帧率不到6帧/秒，会出现跟踪ID跳变，人脸重复抓拍问题。

        【解决】

        业务层保证人脸检测的送帧帧率稳定。
