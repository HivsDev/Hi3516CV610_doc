# 经典蓝牙

BR (Basic Rate) 是 [CHIP_NAME] 的经典蓝牙协议栈 API，支持音频传输、串口通信、组网和数据同步等场景。

## 音频

- [A2DP (Advanced Audio Distribution Profile)](audio/a2dp/a2dp.md) — 高级音频分发，立体声音频传输
- [AVRCP (Audio/Video Remote Control Profile) Controller](audio/avrcp/controller/controller.md) — 音视频遥控（控制端）
- [AVRCP Target](audio/avrcp/target/target.md) — 音视频遥控（被控端）
- [HFP (Hands-Free Profile) AG (Audio Gateway)](audio/hfp/ag/ag.md) — 免提协议（音频网关）
- [HFP HF (Hands-Free)](audio/hfp/hf/hf.md) — 免提协议（免提设备）

## 数传

- [SPP (Serial Port Profile)](spp/spp.md) — 串口仿真，透传数据流

## 组网与同步

- [PAN (Personal Area Network)](pan/pan.md) — 个人局域网，IP (Internet Protocol) 网络共享
- [PBAP (Phone Book Access Profile)](pbap/pbap.md) — 电话本访问，联系人同步

## 通用

- [GAP (Generic Access Profile)](gap/gap.md) — 设备发现、连接管理
